# IPL 2025 ETL Pipeline

This project is a beginner-friendly ETL pipeline built using Python, Pandas, and SQL Server.

The pipeline:
- Extracts IPL 2025 match data
- Transforms and cleans the data using Pandas
- Loads the processed data into SQL Server

## Tech Stack
- Python
- Pandas
- SQL Server
- SQLAlchemy
- pyodbc
- Git & GitHub

## Features
- Data extraction using Python
- Data cleaning with Pandas
- SQL Server integration
